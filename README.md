## Featured Projects

### [SRM Auto Login](https://github.com/SMFawaz24/srm-auto-login)
Published Chrome extension (Manifest V3) that fills and submits the SRM campus network portal login when the session expires. Credentials stay on-device via the Chrome Storage API, and it serves **~2,000 active users**.
`JavaScript` · `Manifest V3` · `Chrome Storage API` · `Webpack`
[Install from Chrome Web Store](https://chromewebstore.google.com/detail/behkfphgkbobbfocneknileklhkkmfjc)

### [Veriflow](https://github.com/SMFawaz24/veriflow) — CSV Validation, Cleaning & Transformation
Revamped 2.1 version of my Data Scaler project: a CSV pipeline that profiles columns, validates, cleans and transforms data, with a REST API and expiring download links.
`Node.js` · `Express` · `REST APIs` · `HTML/JS`
[Live: veriflow.f4w4z.dev](https://veriflow.f4w4z.dev)

### [ATP Analytics](https://github.com/SMFawaz24/atp-analytics) — Player Comparison Dashboard
Interactive dashboard over **65,974 ATP matches (2000–2025)**: head-to-head records, titles by tournament level, surface performance and conditional win rates. Single-file, zero dependencies.
`JavaScript` · `HTML/CSS` · `Data Visualization`
[Live: tennis.f4w4z.dev](https://tennis.f4w4z.dev/)

### [IPL Dashboard (2008–2024)](https://github.com/SMFawaz24/IPL-dashboard)
End-to-end analytics project over **1,095 matches and 260,920 deliveries**: a five-notebook Python cleaning/EDA pipeline feeding a 5-page interactive Power BI dashboard.
`Python` · `Pandas` · `Seaborn` · `Power BI`

### Project Eagle-Eye — AI-Powered Disaster Rescue
Object-detection pipeline using **YOLOv8** to find human survivors in debris from drone footage, with the inference path optimized for low-latency edge processing.
`Python` · `TensorFlow` · `YOLOv8` · `Computer Vision`

### Cloud Infrastructure Stability Analysis
Anomaly detection on simulated cloud-performance metrics (Z-score and Isolation Forest), with experiments tracked in MLflow and a Flask dashboard deployed on AWS EC2.
`Python` · `Scikit-learn` · `MLflow` · `Flask` · `AWS EC2`

### [Interchronos](https://github.com/SMFawaz24/interchronos-astronomy-app) — Astronomy Events Explorer
React + TypeScript SPA that consumes the Wikipedia REST API through custom caching hooks, with a keyword classifier that filters historical astronomical events.
`TypeScript` · `React` · `Wikipedia API`

### [ML-Journey](https://github.com/SMFawaz24/ML-Journey)
My ongoing machine learning notes and notebooks, covering NumPy, covariance/correlation, regression, classification and neural networks.
`Python` · `Jupyter`
